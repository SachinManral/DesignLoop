# Business Requirements Document

## Problem Statement

Engineers preparing for Low-Level Design (LLD) interviews face three consistent hurdles:

- **Fragmented resources** — Theory is scattered across blogs, static books, and passive video tutorials. There's no single place that pairs concepts with code and interactive practice.
- **No realistic practice environment** — Existing platforms focus on algorithmic coding rather than object-oriented system modeling, class responsibilities, and design pattern trade-offs.
- **No architectural feedback** — When practicing LLD problems, candidates receive no automated, senior-level rubric evaluation on SRP, ISP, OCP, or domain modeling.

## Strategic Objectives

**DesignLoop** addresses these gaps through an integrated approach:

1. **Theory Hub** — A 15-module curriculum with UML cards, 5-language code studios, real-world case studies, and inline quizzes.
2. **Practice Arena** — 35+ domain problems across 9 industry verticals with real company tags, live Mermaid diagram modeling, deterministic structural checks, dual-AI rubric scoring, and mutation stress-tests.
3. **Skill Mastery** — Clear visualization of architectural proficiency through 8-dimension rubric telemetry, score timelines, and historical progression.

## User Personas

- **Aspiring FAANG/Tier-1 Engineers** — Looking for a complete, structured roadmap to master LLD interviews.
- **Experienced Mid/Senior Engineers** — Looking to sharpen clean code practices, SOLID principles, and design pattern selection.
- **Engineering Managers & Tech Leads** — Using the platform to benchmark and standardize architectural skills across teams.
